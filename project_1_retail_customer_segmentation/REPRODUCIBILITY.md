# Reproducibility Guide

This guide rebuilds the retail analysis from the public UCI source. Raw data is not
committed to GitHub; the download script retrieves it from the cited repository.

## Environment

- Python 3.11 or newer
- Internet access for the one-time UCI download
- Approximately 300 MB of free disk space

The committed outputs were validated with Python 3.12.13, pandas 2.2.3, NumPy 2.3.5,
scikit-learn 1.8.0, matplotlib 3.10.8, and openpyxl 3.1.5.

## Clean-room run

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r project_1_retail_customer_segmentation/requirements.txt
python download_data.py --project retail
jupyter nbconvert --execute --to notebook --inplace \
  --ExecutePreprocessor.timeout=600 \
  project_1_retail_customer_segmentation/retail_customer_segmentation.ipynb
python project_1_retail_customer_segmentation/validate_outputs.py
```

On Windows PowerShell, activate the environment with `.venv\\Scripts\\Activate.ps1`.

## Expected validation results

The executed notebook must finish without an exception and report all validation checks
as `true`. The headline results should reconcile to:

- 541,909 raw invoice lines
- 4,338 modeled customers
- 18,532 cleaned orders
- GBP 8,911,407.90 in cleaned revenue
- 720 Champions customers, representing 16.6% of customers
- 64.9% of cleaned revenue generated by Champions
- K=4 silhouette score of 0.336
- Mean adjusted Rand index of 0.952 across 25 random seeds (minimum 0.915)

Small floating-point differences across supported package versions are acceptable. Counts
should remain unchanged; use the validated versions above when exact segment membership is
required.

## Interpretation boundary

Reproducibility confirms that the calculations can be regenerated from the cited data. It
does not establish causal campaign effects, profitability, or generalizability beyond the
retailer and period represented in the source.
